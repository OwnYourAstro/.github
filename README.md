# .github

This repository holds the organization profile for
[OwnYourAstro](https://github.com/OwnYourAstro) and the community health
files shared by every repository in the organization.

- [`profile/README.md`](profile/README.md) — what renders on the organization
  landing page.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution rules, including the
  clean-room policy that applies to all projects here.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)
- [`SECURITY.md`](SECURITY.md)
- [`TRADEMARKS.md`](TRADEMARKS.md)
- [`docs/`](docs/) — scope, roadmap, architecture, and the clean-room process.
- [`.github/`](.github/) — issue and pull request templates.
